<objective>
## Goal
Add a GitHub Actions workflow that runs the four project gates on Ubuntu 24.04 for every push and pull
request: a warning-free build, `make test`, the editor smoke test, and `check_docs.py`. Before anything
leaves this machine, prove it works by running the exact same steps in a fresh clone inside WSL.

## Purpose
The rename (Phase 2) and every later milestone change many files at once. An automatic gate means a
broken build or test can't land unnoticed, and future contributors get the same checks without needing WSL.

## Output
- `.github/workflows/ci.yml`
- A local fresh-clone rehearsal result (all four gates green)
- If you approve the push: a green Actions run on `phase-1-dev-environment`, with its URL recorded
</objective>

<task type="auto">
  <name>Task 1: Write the CI workflow and document it</name>
  <files>.github/workflows/ci.yml, docs/development/building-and-testing.md, CLAUDE.md, CHANGELOG.md</files>
  <action>
    ci.yml:
      name: CI
      on: push to [main, "phase-*"]; pull_request to [main]
      permissions: contents: read
      concurrency: one run per ref; cancel in-progress runs
      job "linux" on ubuntu-24.04, timeout-minutes: 20, steps:
        - actions/checkout@v4
        - sudo apt-get update && sudo apt-get install -y clang make libcurl4-openssl-dev
        - clang --version (logged)
        - make 2>&1 | tee build.log; then fail if build.log contains "warning:"
          (the project rule is no warnings; make already fails on errors)
        - make test
        - actions/setup-node@v4 with node-version 20, then node editors/vscode/test/smoke.js
        - python3 tests/check_docs.py
    Docs: add a short CI paragraph to building-and-testing.md ("Continuous checks…"), a one-line CI pointer in
    CLAUDE.md, and a CHANGELOG line under Unreleased.
    Commit: ci(01-03): GitHub Actions workflow for build, tests, smoke test and docs check (with the attribution line).
    Avoid: secrets, caching layers and matrix builds (Windows CI is v0.4 phase 9), and README badges (they'd
    show "no status" until the first run).
  </action>
  <verify>In WSL: python3 parses ci.yml with yaml.safe_load; a script asserts the triggers, runs-on, timeout and the four gate commands are present</verify>
  <done>AC-1 and AC-5 satisfied</done>
</task>
