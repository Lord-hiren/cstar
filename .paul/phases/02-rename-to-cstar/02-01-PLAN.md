<objective>
## Goal
Make the command line say **cstar**:
- a `cstar` binary, with a `pentest` alias
- `.cst` as the canonical source extension
- `index.cst` as the default entry file
- `cstar build hello.cst` → `./hello`
- `CSTAR_PATH` for module search
- `~/.cache/cstar` and `cstar-*` temp folders

Every old name (`.pen`/`.pent`, `PENTEST_PATH`, the `pentest` command) keeps working until v0.4. The test
harness, CI and the normative SPEC CLI sections change in the same plan, so `make test` stays green after
every commit.

## Purpose
The CLI is the first thing every user touches, and it's what the rest of the rename builds on: test files
(02-02), internals (02-03) and docs (02-04). Keeping the old names working means nothing breaks mid-rename.

## Output
- `build/cstar` and `build/pentest` (an alias of the same driver)
- An updated harness with new checks for `.cst`, legacy names, `index.cst`, the alias and `CSTAR_PATH`
- SPEC §2, §10, §11.6 and §14.2 describing the cstar CLI
</objective>

## Decisions (made 2026-11-05)
- Source extension **`.cst`**. Legacy `.pen` and `.pent` are accepted until v0.4.
- **`index.cst` is the default entry.** `cstar run`, `cstar build` and `cstar check` with no file use
  `./index.cst`. If it doesn't exist: usage error, exit 2. Bare `cstar` with no arguments still prints usage
  and exits 2, as today.
- **Build output** is the source basename without its extension, in the current directory
  (`tools/hello.cst` → `./hello`, `index.cst` → `./index`, `x.pen` → `./x`). No more `.pentest`. If that path
  is an existing directory (e.g. `lib.cst` next to a `lib/` folder): usage error suggesting `-o`.
- **Module search:** importing file's folder → CWD → `$CSTAR_PATH` entries → `$PENTEST_PATH` entries
  (legacy). In each root, candidates are tried in this order: `rel.cst`, `rel.pen`, `rel.pent`,
  `rel/__init__.cst`, `rel/__init__.pen`, `rel/__init__.pent`. The first match wins.
- **Cache and temp names:** `$XDG_CACHE_HOME/cstar/` (default `~/.cache/cstar/`); `$TMPDIR/cstar-XXXXXX/`;
  `cstar-hash-XXXXXX`. Cached programs are stored as `<key>.bin` instead of `<key>.pentest`. The old
  `~/.cache/pentest` is just no longer used (safe to delete).
- **Version line** becomes `cstar 0.2.1` (the number changes only in plan 04-01).
- **Out of scope here:** internal names (`namespace pentest`, `pt_`, `pentest_rt.*`) are plan 02-03, and
  "Pentest" in runtime error messages is 02-02.
