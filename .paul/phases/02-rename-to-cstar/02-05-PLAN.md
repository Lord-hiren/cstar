<objective>
## Goal
Finish the rename in the words people read:
- **SPEC (D-6):** specify the five SIMD vector builtins and correct the builtin count from seventy to
  seventy-eight.
- **Every living document:** README, SPEC, contracts, guides, internals, development docs, the CHANGELOG
  header and the docs checker say cstar. Use `cstar` commands and `.cst` files, and keep the legacy names
  only where a sentence is about legacy support.

This is the last plan of Phase 2, whose goal is "everything user-facing says cstar". After it, a new reader
meets one name everywhere. The normative SPEC also matches the compiler again: today it has no vector
builtins and the wrong count.

  §3.5, §5.11.1, §8 and §10
- Living docs and doc tools renamed. The remaining `Pentest`/`pentest`/`.pen` mentions form an explicit
  allowlist: legacy support, history, fixture data, the dev path `~/Projects/Pentest`, and benchmark
  tooling (D-11)
- Phase 2 complete; the phase transition follows UNIFY
