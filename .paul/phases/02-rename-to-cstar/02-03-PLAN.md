<objective>
## Goal
Rename the VSCode extension to **cstar** without breaking anyone's existing setup:
- identity `cstar-lang`, language id `cstar`
- `.cst` files, with `.pen`/`.pent` still associated
- grammar scope `source.cstar`
- settings `cstar.*`, with `pentest.*` still honored
- commands `cstar.*`, with the old ids still registered
- runs the `cstar` CLI (falls back to `pentest`), and hover/completion text says cstar

Also fix D-7: the editor learns the five SIMD vector builtins it's missing
(`fvec`, `ivec`, `fvec_fill`, `ivec_fill`, `dot`).

## Purpose
The editor is where users spend their time. After this plan, opening a `.cst` file gives full support
under the cstar name, and the editor's builtin list matches the compiler's 78 names again.

## Output
- The renamed extension, plus an updated smoke test (new names + checks for the legacy fallbacks and D-7)
- The install script, extension README, editor-extension guide and CHANGELOG updated
- A visual check in your VSCode (checkpoint)
</objective>

## Facts found during planning (2026-11-05)
**package.json:**
- identity: name/publisher `pentest-lang`
- language id `pentest`, extensions `.pen`/`.pent`
- grammar `source.pentest`, snippets language `pentest`
- `activationEvents` `onLanguage:pentest`, `configurationDefaults['[pentest]']`
- commands `pentest.run`; menus use `resourceLangId == pentest`
- settings `pentest.executable` (default `pentest`), `pentest.diagnostics`, `pentest.diagnosticsDelay`

**extension.js:**
- `getConfiguration('pentest')` (3 places)
- `languageId === 'pentest'` (3)
- `createDiagnosticCollection('pentest')`, `d.source = 'pentest'`, terminal name `'Pentest'`
- commands `pentest.run`, `pentest.toggleLineComment`
- `cliCandidates()` tries: the configured name or `pentest` on PATH, `~/.local/bin/<name>`,
  `~/Projects/Pentest/build/<name>`
- temp file `pentest-check-…pen`; env `PENTEST_PATH`
- 20+ ```` ```pentest ```` code fences and `appendCodeblock(…, 'pentest')`
- "Pentest" / "not available in Pentest" in hover and warning texts

**Grammar and smoke test:**
- The grammar has 39 scope names ending in `.pentest`.
- smoke.js has 222 mentions, mostly scope assertions like `'keyword.control.pentest'`, plus
  `pentest.run`, `source.pentest`, the language id and file paths.

**D-7:** `fvec`, `ivec`, `fvec_fill`, `ivec_fill` and `dot` are missing from extension.js, the grammar and
the smoke test. Their signatures and contracts are in docs/guide/builtins.md ("SIMD vectors").

**Install:**
- install-vscode-extension.sh symlinks `editors/vscode` to `~/.vscode/extensions/<publisher>.<name>`, and
  removes only the current id's folder.
- So after the id change, an old `pentest-lang.pentest-lang` link would load the same folder twice.
- The extension is not installed on this PC right now.

**Windows note:** the cstar CLI is Linux-only (WSL), so on Windows live diagnostics fall back to the
"CLI not found" warning. That's expected until v0.4.
</context>
