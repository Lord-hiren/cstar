<objective>
## Goal
1. The five user-visible messages that name the language say **cstar** instead of Pentest. The code, the
   SPEC quotes and the test expectations change together, because quoted messages are normative.
2. All test programs move from `.pen` to `.cst`: 365 cases and 6 module fixtures. The harness runs
   `tests/cases/*.cst`, and the suite stays at 376/0.

## Purpose
Users see these messages, and the test suite is the main body of example code in the repo. After this plan,
nothing a user runs or reads in the tests says Pentest. The legacy `.pen` path is still covered by the
harness check `legacy_extensions`.

  `pow() 3rd argument must be positive (cstar does not support negative moduli)`,
  `chr() surrogates are not allowed (cstar strings are UTF-8)`
- `tests/cases/**/*.cst`, plus the harness, `.gitignore`, CLAUDE.md and the contributor docs updated
