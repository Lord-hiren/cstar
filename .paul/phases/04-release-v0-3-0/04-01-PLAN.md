<objective>
## Goal
Turn the work of Phases 1–3 into the release **cstar 0.3.0**:
- `cstar --version` prints `cstar 0.3.0`;
- SPEC and the docs stop calling shipped work "unreleased";
- CHANGELOG has a `0.3.0` section;
- an annotated `v0.3.0` tag sits on a release commit that passes every gate.

Then publish it to GitHub only in the way you choose.

## Purpose
v0.3 is the "cstar Foundation" milestone: the rename, a clean repo with CI, and no open known issues. Everything later
(the v0.4 SDK, installers, packages) refers to released versions, so this is the first release under the cstar name.

## Output
- Version `0.3.0` in the driver and the editor extension manifest.
- SPEC and docs that describe 0.3.0 as released.
- CHANGELOG `## [0.3.0] — 2026-11-13`.
- History timeline rows.
- A local annotated tag `v0.3.0`.
- Release notes for a GitHub Release page, in the scratchpad.
- With your approval: `main` and the tag on GitHub, and a green CI run on `main`.
</objective>
